# electrobisturi
Es una plataforma web que no reemplaza al electrobisturí, sino que ayuda a gestionarlo: registra su información técnica, programa y controla su mantenimiento, guarda evidencias, y tiene un asistente de inteligencia artificial que responde preguntas técnicas basándose solo en la documentación que el equipo cargue (manuales, protocolos, normas)
